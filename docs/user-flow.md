# VN-AI V1 页面与用户流程

## 1. 页面结构

```text
内容项目列表
├── 新建内容项目
├── 文章与事实审核
├── 内容生成工作台
├── 单条内容编辑器
├── 导出中心
└── 设置
    ├── 平台规则
    ├── 品牌语气
    ├── CTA 模板
    ├── 敏感词
    └── 用户权限
```

## 2. 内容项目列表

展示：

- 项目名称
- 文章标题
- 分类
- 语言
- 当前阶段
- 已生成平台数量
- 待审核数量
- 更新时间

操作：

- 新建项目
- 继续编辑
- 查看内容
- 复制项目
- 归档项目

## 3. 新建项目

### Step 1：输入文章

支持输入公开文章 URL、上传 DOCX 或粘贴文本。URL 抓取由服务端完成，避免浏览器跨域限制。解析后展示：

- 标题
- 字数
- 段落数量
- 检测到的语言
- 检测到的链接
- 解析异常提示
- 来源 URL 和 canonical URL

### Step 2：填写内容配置

- 文章分类
- 目标用户
- 品牌语气
- 语言
- 官网链接/预留链接
- CTA
- 计划发布时间
- 选择输出平台

### Step 3：开始解析

系统生成事实基础包。解析期间不可生成最终平台内容。

## 4. 事实审核页

推荐三栏布局：

```text
左栏：原文章
中栏：摘要、事实、数字、实体
右栏：风险提示、来源和审核操作
```

用户可以：

- 确认事实
- 编辑事实
- 删除事实
- 添加来源
- 标记为敏感
- 标记为不可用于社交媒体
- 批准进入生成阶段

### 必须阻止的情况

- 文章正文为空
- 没有任何可识别事实
- 关键数字未确认
- 高风险文章未完成人工审核

## 5. 内容生成工作台

使用平台卡片或 Tab 展示：

```text
官网 SEO | Facebook | Threads | LinkedIn | X
Instagram | 短视频 | Community | Push | LIVE | FAQ
```

每张卡片显示：

- 输出数量
- 生成状态
- 审核状态
- 风险数量
- 重复度提示
- 最后更新时间

操作：

- 生成
- 重新生成
- 批量批准
- 打开编辑器
- 导出当前平台

## 6. 单条内容编辑器

```text
左侧：文章来源和 Fact 引用
中间：内容编辑区
右侧：平台检查、风险检查、审核记录
```

右侧检查项目：

- 字符数
- 必填字段
- Fact 引用
- 未支持声明
- 敏感词
- 投资建议风险
- CTA
- 重复内容

操作：

- 保存草稿
- 重新生成
- 只修改 Hook
- 只修改 CTA
- 翻译
- 提交审核
- 批准
- 驳回并填写意见

## 7. 导出中心

支持按项目、平台和内容类型导出。

### 导出格式

- Markdown：适合官网和开发使用
- DOCX：适合编辑团队
- XLSX：适合运营排期
- JSON：适合后续 API 或 CMS 对接
- ZIP：完整内容项目包

### XLSX 建议字段

```text
项目名称
平台
内容类型
标题/Hook
正文
CTA
官网链接
目标人群
建议时间
Fact IDs
风险等级
审核状态
审核人
```

## 8. 典型用户操作

```text
运营人员创建项目
→ 上传官网文章
→ 配置分类、语言、目标用户和 CTA
→ 审核 AI 提取的事实
→ 点击生成全部平台内容
→ 逐个平台检查和修改
→ 提交审核
→ 审核人员批准
→ 导出给官网、社媒和 App 团队
```

## 9. 错误处理

- URL 无法访问或不是 HTML：提示改用 DOCX/粘贴文本
- 页面存在反爬或登录限制：提示改用 DOCX/粘贴文本
- DOCX 无法解析：提示重新上传或粘贴文本
- 文章过短：允许继续，但提示内容可能不足
- AI 生成失败：支持单个平台重试
- Fact 无法匹配：标记为高风险，不允许直接批准
- 平台内容超长：显示具体超出字符数
- 发现敏感词：高亮并要求人工处理
- 官网链接为空：允许生成，但 CTA 标记为待补链接
