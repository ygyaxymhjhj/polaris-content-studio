# VN-AI 内容分发工具 V1 产品需求文档

## 1. 产品定位

将一篇准备发布到公司官网的 SEO 文章，转换为一套经过事实约束、平台适配和人工审核的多渠道内容分发包。

> V1 重点是“文章 → 内容资产 → 审核 → 导出”，暂不实现全平台自动发布和全自动智能 Push。

## 2. V1 目标

- 减少人工改写和内容制作时间
- 保证所有输出内容来自原始文章
- 针对不同平台生成不同表达方式
- 提供统一的审核、修改、版本管理和导出能力
- 为后续自动发布、Push 个性化和数据优化预留结构

## 3. 用户角色

### 内容运营人员

- 创建项目、上传文章
- 审核事实和 AI 内容
- 修改、批准、导出内容

### 编辑/审核人员

- 检查事实、语气、敏感内容和合规风险
- 驳回并填写修改意见

### 管理员

- 配置平台规则、品牌语气、敏感词和用户权限

## 4. 输入

### 必填字段

- 项目名称
- 文章标题
- 文章正文、DOCX 文件或公开文章 URL
- 文章语言
- 文章分类
- 目标用户
- 主要 CTA

### 选填字段

- 官网链接或预留链接
- 文章来源链接
- 抓取后的 canonical URL
- 计划发布时间
- 相关 Broker、KOL、产品或监管机构
- 敏感等级
- 品牌语气

## 5. 内容处理流程

```text
创建项目
  ↓
输入 URL、上传或粘贴文章
  ↓
抓取/解析正文
  ↓
提取摘要、事实、数字和实体
  ↓
人工确认事实包
  ↓
选择输出平台
  ↓
生成平台内容
  ↓
事实、长度、敏感词和重复度检查
  ↓
人工编辑和审核
  ↓
批准并导出
```

## 6. 输出内容

### 6.1 官网 SEO 发布包

- 清理后的文章正文
- SEO Title
- Meta Description
- URL Slug
- 摘要
- H1/H2 结构
- 关键词
- 内链建议
- 封面图 brief
- 图片 Alt Text
- FAQ
- CTA

### 6.2 事实基础包

- 一句话摘要
- 短摘要和长摘要
- 关键事实列表
- 所有数字、日期和名称
- 原文出处段落
- 来源链接
- 禁止扩展的结论
- 风险和敏感项

### 6.3 Facebook

生成 2 条不同角度的帖子。每条包含：Hook、正文、讨论问题、CTA、图片建议、Hashtags、Fact ID。

### 6.4 Threads

生成 1 条主帖和 3–5 条后续回复。需要有讨论问题和回复引导。

### 6.5 LinkedIn

生成 1 条专业观点帖，包含行业影响、商业视角、事实依据和 CTA。

### 6.6 X

支持单条短帖和 4–7 条 Thread 两种形式，提供字符数检查。

### 6.7 Instagram Carousel

生成 6–8 张卡片的标题、正文、视觉建议、封面文案、Alt Text 和 CTA。V1 生成文案与设计 brief，不自动生成最终图片。

### 6.8 TikTok/Reels/Shorts

生成 1 份 40–70 秒的配音文案：完整可朗读的口播文本（无时间轴、屏幕文字、画面方向），附一句发布配文。

### 6.9 App Community

支持 Poll、Q&A、Discussion、Mission 四种模板，输出标题、背景、选项、官方首条回复和互动问题。

### 6.10 App Push

生成 3 个版本，每个版本包含 Title、Body、CTA、Deep Link、建议人群、建议时间和频控建议。V1 只生成和导出，不自动发送。

### 6.11 KOL LIVE

输出直播标题、简介、主持流程、讨论重点、观众问题、互动环节和结束 CTA。

### 6.12 FAQ

默认生成 5 组问答。每组保存原文依据、风险提示和审核状态。

## 7. 内容审核规则

每条资产需要检查：

- 是否使用了原文没有的信息
- 数字、日期和名称是否准确
- 是否关联了 Fact ID
- 是否有金融、Broker、法律或监管风险
- 是否存在绝对化或投资建议表达
- 是否包含虚构评论、案例或曝光证据
- 是否符合平台长度和格式
- 是否有明确 CTA
- 是否和其他资产重复

高风险内容必须人工批准后才能导出。

## 8. 内容状态

```text
DRAFT → PROCESSING → FACT_REVIEW → GENERATED → NEEDS_REVIEW → APPROVED → EXPORTED
```

驳回时进入 `REVISION_REQUIRED`，保留原版本和审核意见。

## 9. V1 验收标准

- 可以上传 DOCX 或粘贴文章正文
- 可以成功解析正文并保留段落结构
- 可以生成事实基础包
- 事实包可以人工修改、确认和删除
- 可以选择平台并生成对应内容
- 每条内容可以查看其事实依据
- 支持编辑、重新生成和版本保存
- 可以标记风险和审核状态
- 可以导出 Markdown、DOCX、Excel、JSON 或 ZIP
- 不支持的内容必须显示警告，不允许静默发布

## 10. V1 暂不实现

- 社交平台自动发布
- Push 自动发送
- 基于真实用户行为的自动分群
- 自动选择最佳发送时间
- 自动图片设计和视频剪辑
- 自动根据平台数据训练模型
