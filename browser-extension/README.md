# Polaris 文章导入扩展（内测版 0.1.0）

适用 Chrome / Edge 桌面版。首次安装一次，以后直接从编辑自己的浏览器读取已打开文章，不再让服务器请求 WikiFX。

## 安装
1. 下载 ZIP，解压到固定目录（安装后不要删除或移动）。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，选中包含 manifest.json 的目录。
4. 在浏览器扩展菜单中固定 Polaris Article Import。
5. 企业管理的浏览器如果禁止开发者扩展，需要联系 IT；不要绕过公司策略。后续可通过商店或企业策略正式分发。

## 使用
1. 在浏览器正常打开 WikiFX 文章，等待正文显示。如需验证码或登录，请本人正常完成。
2. 点击 Polaris 扩展图标，然后“读取当前文章”。
3. 核对标题、正文、原文链接；可在预览里删去无关内容。图片内容不做 OCR。
4. 目标选择 LAN 192.168.220.109:13300（本地测试可选 localhost:3002）。
5. 点击“确认并发送到工具”，传输期间保持弹窗开启。工具标签页会在收到后打开。
6. 在工具内再次点击“确认导入文章”，才会替换来源，并清空原事实和素材。
7. 分析来源、人工确认事实、生成素材。导入成功不代表原文信息已独立核实。

原文读取来自当前浏览器 DOM，不访问服务器抓取接口。若工具正在生成或编辑器未关闭，先完成操作再发送。安装扩展后，如工具已打开很久，请先保存工作并刷新一次以加载接收脚本。

## 权限与隐私
- activeTab：仅在用户主动点击扩展后授权当前文章标签页；scripting：提取当前页面已显示的正文。
- 仅允许连接配置的内网和本机工具地址，脚本另行限制具体端口及根路径；不会向任意第三方上传。
- 不请求 cookies、history、webRequest 等权限；不读取 Cookie、密码、表单输入或隐藏脚本数据。
- 发送前需预览确认，发送内容为标题、正文、原文链接及采集时间等非凭据元数据。
- 原文链接去掉 query 和 fragment，避免误带跟踪或会话参数。因此本版首先适配 WikiFX 路径型新闻 URL；依赖查询参数定位的其他网站需人工检查来源链接。
- 读取已登录文章也可能含私人文字，发送前必须检查，遵守访问和内容使用授权。
- 内网目标目前是 HTTP，只用于可信公司网络；正式使用建议 HTTPS。

## 限制
不能绕过验证码、登录、反爬、付费或网站访问限制。页面没有正文、只有拒绝访问提示时无法读取。网站改版可能需要更新选择器。导入不自动发布，也不解决 AI 供应商地区限制。

扩展发送只把内容交到当前用户的工具标签页，不经过新的匿名上传 API，不写共享数据库；仍需该用户确认导入。此版本不提供跨账号共享项目能力。

## 更新
重新下载并替换目录文件，在扩展管理页点击重新加载，再刷新工具页面。不要把 API 密钥放入扩展。
